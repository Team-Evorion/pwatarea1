## 📌 Descripción del Proyecto

Este repositorio contiene el desarrollo de la **Tarea Práctica 1 de Programación Web Avanzada**, realizada por estudiantes de la carrera de Ingeniería en Sistemas Inteligentes de la Universidad Bolivariana del Ecuador.

El proyecto reúne **10 ejercicios prácticos**, organizados mediante una página principal que permite navegar entre ellos.

Se aplicaron conocimientos de **HTML5, CSS3 y JavaScript**, incluyendo estructura web, enlaces, tablas, formularios, navegación, diseño responsivo e interactividad.

***

## 📚 Ejercicios Desarrollados

| Ejercicio | Descripción |
|-----------|-------------|
| **01** | Presentación y estructura básica de HTML |
| **02** | Enlaces y contenido personal |

| **04** | Formulario de registro con validación |
| **05** | Biografía y navegación interna |
| **06** | Control de rango interactivo |
| **07** | Menú de navegación con estilos CSS |
| **08** | Navegación adaptable a dispositivos móviles |

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura y contenido de las páginas.
- **CSS3:** Estilos, colores, tipografías y animaciones.
- **JavaScript:** Funcionalidades interactivas.
- **Git:** Control de versiones del proyecto.
- **GitHub:** Almacenamiento y trabajo colaborativo.
- **GitHub Pages:** Publicación de la página web.

***


## 🚀 Ejecución del Proyecto

**Opción 1: Desde GitHub Pages**

1. Acceder al enlace de la página web.
2. Visualizar el menú principal.
3. Seleccionar cualquiera de los 10 ejercicios.
4. Explorar las funcionalidades desarrolladas.

**Opción 2: Desde una computadora**

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador.
4. Navegar entre los ejercicios.

**No es necesario instalar dependencias adicionales.**

- Comprender la estructura de documentos HTML.
